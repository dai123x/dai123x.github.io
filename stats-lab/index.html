这条曲线为什么重要？

中心极限定理说的是：只要观测之间独立、方差有限，样本均值的抽样分布会随着 n 增大趋近正态， 而且这个正态的均值等于总体均值 μ、标准差等于 σ/√n —— 后者就是「标准误」。

注意图 B 的横轴比图 A 窄得多，而且随 n 增大越来越窄。这就是为什么「平均值」这种统计量如此好用： 单个观测可能很吵，但它的平均值的波动被 1/√n 压下去了。

两个前提别忘：独立性（观测之间不能强相关）与有限方差。 厚尾到方差都不存在的分布（比如 Cauchy），这条定理不成立——实验 03 会让你看到厚尾的代价。

百分位区间和正态近似区间，该信哪个？

百分位区间直接取 bootstrap 分布的 2.5% 与 97.5% 分位数——不假设任何分布形状，是默认选择。 正态近似区间用 x̄ ± 1.96·SE，只有在 bootstrap 分布近似对称时才靠得住。

把 n 拖到 5 再点「模拟覆盖率」：95% 的区间实际只盖住真值 76% 上下； n 提到 50 才回到 93% 左右（本页 M=200 实测）。因为对数正态右偏， 小样本的 bootstrap 分布本身也偏，百分位区间会系统性偏移。这不是代码错了，这是 bootstrap 的真实局限， 也是它需要 n 别太小的原因。

「相对效率」怎么读？

SE(med)/SE(x̄) 就是中位数相对均值要多花多少样本量才能达到同样的精度。这个比值 ≈ 1 时两者打平； 1.25 意味着中位数需要多约 1.25² ≈ 1.6 倍的样本量。

正态总体下这个比值约 1.253（理论值 √(π/2)）—— 均值赢得干净利落，因为它用上了每一个观测的具体数值。 但换成 t(3) 或掺了离群点的污染正态，均值会被极端值反复拽偏，比值迅速跌到 1 以下， 中位数反而更准。这就是「稳健性」的价格：在理想世界里吃点亏，换极端情况下的不崩盘。

这不是数字游戏，是真实发生过的事

当分组变量同时影响「谁进入哪一组」和「结果」时，合并统计量就会把组间差异和构成差异混在一起。 本实验里，A 组重症占比高，所以它被迫在更难的人群里作战，合并成功率被拖低。

识别它的办法很朴素：把可能影响分配的因素都分层看一遍。点「随机化分配」把两组构成拉平， 悖论立刻消失——这正是随机对照试验（RCT）要随机化的原因：随机化让构成差异在期望上归零。

口径说明

样本方差用 n−1（无偏）；偏度用 Fisher–Pearson 标准化矩；正态近似区间用 z 分位数，百分位区间用 bootstrap 分位数。中位数在偶数样本量时取中间两个值的平均。

已知取舍

为了交互流畅，重复次数上限设为 5000、覆盖率元实验固定 200 份样本，因此读数会有约 1–2% 的蒙特卡洛抖动。抖动是模拟的常态，不是 bug。
