📌 案例背景与核心业务痛点

在现代汽车动力总成制造车间中，发动机装配生产线属于高度分工的串联流水线。产线整体节拍（Takt Time）取决于最慢工序（瓶颈工序）。 作业人员动作离散性、物料供给波动（AGV 配送延误）以及偶发非增值活动（MUDA），常常导致流水线各工位节拍呈现出高方差与冲击波动。

本案例依托作者在一汽丰田发动机工厂的现场作业测定与工业工程实践，以发动机总装 5 大核心装配工位（缸体上线、曲轴安装、活塞连杆组装、气门配气、总装检验）为分析对象， 运用应用统计学中的多元时间序列建模、分布检验拟合与统计过程控制（SPC），对各工序作业节拍进行异常诊断、趋势量化与容量平衡预测。

📈 时间序列建模与动态预测 (ARIMA)

由于生产过程中工序节拍受到装配人员生理节律疲劳、机器温度积累及前工序来料累积影响，各生产周期的工序节拍存在显著的自相关性。

1. 平稳性检验（ADF 单位根检验）

ADF 检验统计量: t = -26.9372, p-value = 0.0000e+00
1% 临界值: -3.434, 5% 临界值: -2.863 ➔ 序列高度平稳，d = 0

2. ARIMA(1,0,1) 参数估计与残差诊断

采用最大似然估计（MLE）拟合得到自回归滑动平均模型方程：

X_t = 58.457 + 0.4527 \cdot (X_{t-1} - 58.457) + \epsilon_t + 0.0178 \cdot \epsilon_{t-1}
其中：自回归系数 φ_1 = 0.4527 (z = 10.935, P < 0.001, 极显著)，残差方差 σ² = 41.64

统计学意义解释：自回归项显著为正（0.4527），证明前一周期的工时延误有约 45.3% 会传递至下一周期，揭示出瓶颈工序存在典型的“扰动滞后扩散效应”。

🚀 精益工业工程改善与产线平衡优化

产线平衡效率（Line Balancing Efficiency, LBE）计算公式如下：

LBE = [ Σ (T_i) / ( k × max(T_i) ) ] × 100%

改善前：总装 5 个工位总平均作业时间为 246.79 秒，最大瓶颈为 OP30（58.46 秒），初始平衡率为 84.43%。

改善措施： 1. 结合视频动作分析（Motion Study）剔除 OP30 中物料翻找与工具往返拿取的非增值活动（MUDA），单循环缩减 6.7 秒；
2. 配合 AGV 配送物料路径重组，将曲轴与连杆配套备料前置，将 OP30 周期稳定控制在 51.7 秒以内。

改善后效益：产线平衡率由 84.43% 跃升至 92.71%（综合效率净提升 +8.28%），全线每日增产装配能力预估达到 12.6%。

💻 可复现核心分析代码 (Python)

以下为该案例所运行的数据检验与建模核心逻辑代码（支持本地一键运行复现）：

import numpy as np
import pandas as pd
from scipy import stats
import statsmodels.api as sm
from statsmodels.tsa.stattools import adfuller

# 1. 瓶颈工序时序平稳性检验 (ADF Test)
adf_res = adfuller(df['OP30_活塞连杆'])
print(f"ADF Statistic: {adf_res[0]:.4f}, p-value: {adf_res[1]:.4e}")

# 2. ARIMA(1,0,1) 参数估计
model = sm.tsa.ARIMA(df['OP30_活塞连杆'], order=(1, 0, 1)).fit()
print(model.summary().tables[1])

# 3. 产线平衡率测算
total_time = df.mean().sum()
bottleneck = df.mean().max()
balance_efficiency = (total_time / (bottleneck * len(df.columns))) * 100
print(f"产线平衡效率: {balance_efficiency:.2f}%")
