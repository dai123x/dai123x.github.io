# 长春工业大学 · 全景立体地图

一个零依赖、可离线运行的交互式三维校园地图（纯 HTML + Three.js，无需安装任何环境）。

## 🚀 使用方法

**双击 `index.html`** 即可在浏览器中打开（Chrome / Edge / Firefox 均可），完全离线可用。

也可以在本目录起一个本地服务后访问，例如：

```bash
python -m http.server 8642
# 浏览器打开 http://127.0.0.1:8642/
```

## ⚡ 性能优化实录（2026-10）

以 Chrome 实测北湖校区默认场景为基准：

| 指标 | 优化前 | 优化后 | 变化 |
|------|--------|--------|------|
| Draw Calls | 1355 | ~630 | **-53%** |
| 几何体数量 | 1179 | 480 | -59% |
| 三角面数 | 12.0 万 | 12.0 万 | 不变（视觉零损失） |
| 切校区显存泄漏 | 每次泄漏全部标签贴图 | 已修复 | Sprite 贴图随场景释放 |
| 截图后台缓冲 | 常驻 preserveDrawingBuffer | 同帧读取 | 每帧节省一次全屏拷贝 |
| 子资源缓存 | 全站 no-cache 强制重下 | 恢复缓存 + 版本号失效 | three.min.js(590KB) 等不再每次重下载 |
| 脚本加载 | 串行阻塞解析 | 全部 defer 并行下载 | HTML 解析与脚本下载重叠，首屏更快 |

关键手段：
1. **静态合批**——道路 449 段合并为 1 个网格；夜景霓虹描边合并为 1 条 LineSegments；草地斑块合并；每栋建筑内部「完全同外观材质」的零件（台阶/立柱/女儿墙等）自动合并，材质签名一致才合并，视觉 100% 等效。
2. **按需阴影**——阴影贴图仅在场景/光照/季节变化时重绘（`shadowMap.autoUpdate=false`），移动端降为 1024 分辨率。
3. **拾取加速**——每栋楼预计算包围球，点击/悬停先做射线-球粗筛再精确求交。
4. **设备分级**——移动端/低核设备自动关闭 MSAA、pixelRatio≤1.5、PCF 软阴影降档。
5. **缓存策略**——移除 `Cache-Control: no-cache` 等三条 meta（它们会让浏览器对每个子资源都重新下载），改用 `?v=` 版本号做变更失效；10 个 `<script>` 统一 `defer`，让脚本下载与 HTML 解析并行。

## 📚 数据来源与真实还原规范

全校区楼宇数据、建筑轮廓、朝向与层数严格对照 **OpenStreetMap (OSM) 空间矢量数据**、校基建处规划图纸以及「长工大表白墙」2026 最新校区平面图深度对齐：

1. **北湖校区（西区与东区）**：
   - **博厚图书馆**：根据实测 142m × 50m 真实长宽建模，还原 5 层 3.3 万㎡体量与中央挑高采光中庭。
   - **西区教学主楼 / 科技大楼**：核心科技塔楼拔高至 12 层（高 45m），东西两侧延伸 6 层本科教学翼楼与阶梯教室。
   - **学生公寓生活区**：按实景三列布局，完整加入 1-10 栋之间的 **知理苑（3F）、知行苑（3F）、知义苑（3F）、雅逸苑（3F）、知远苑（3F）** 五大生活服务苑，以及 4 层的西区大食堂（58m × 76m）。
   - **东区主教学楼**：按 OSM 矢量绘制长达 240 米的弧形综合教学中枢，连同 97m 艺术技术楼（艺术设计学院）、97m 信息传播楼（新闻传播学院）与 92m 大学生文体活动中心。
   - **东区生活苑群**：精准补齐 **知信苑（2F）、雅馨苑（2F）、雅慧苑（2F）** 及 4 层东区主食堂。

2. **南湖校区（历史校区）**：
   - **主教学楼（电气与电子工程学院）**：1950 年代苏式新古典主义标志性建筑，凹字形对称轴线布局，赭色红砖外立面配以典雅歇山绿琉璃瓦檐顶与高耸正门立柱门厅。
   - **双图书馆历史延续**：南湖同时保留具有历史风貌的**老图书馆**（翡翠绿歇山顶建筑）与现代化的**新图书馆**（86m × 78m 5层大体量新馆）。
   - **宿舍区真实单体化**：彻底废除模糊的概括性合称，完全按 OSM 测绘拆分为男寝 1 栋、2 栋、3 栋、4 栋、5 栋、6 栋、女寝 7 栋与 8 栋（国防生公寓）。

**38 栋楼宇的立面直接采用官方发布的效果图/实景照片贴图**（img/ 目录，仅北湖校区）：
- 北湖东区各楼效果图：基建处《北湖校区东区建设项目情况简介》 https://jjc.ccut.edu.cn/info/1087/1100.htm
- 博厚图书馆实景照片：校新闻网《北湖校区迎新地标》 https://ccutnews.ccut.edu.cn/info/1027/5633.htm
- 南湖校区米黄色调与绿色坡屋顶、白色弧顶体育馆均按官方实景与鸟瞰图配色还原（无立面贴图）
