# 个人专属网址管理系统 (网站预存)

专为解决日常常用网址查找繁琐、翻阅 Chrome 历史记录浪费时间而设计的轻量化个人导航系统。

---

## ✨ 核心亮点

1. **双击即启**：双击 `启动网址管理系统.bat`，即可自动启动本地服务并唤起默认浏览器，无需配置复杂的环境。
2. **本地文件自动同步**：所有网址的新增、编辑、删除与分类调整，均会自动、实时保存在当前目录下的 `urls.json` 中，绝不上传任何第三方云端，完全私有可控。
3. **毫秒级模糊搜索**：支持在顶栏直接输入网站名称、网址域名或备忘说明，即刻精准过滤目标。支持快捷键 `/` 一键激活搜索框。
4. **分类/分组管理**：支持自定义分类与 Emoji 图标（如：⭐ 常用推荐、🛠️ 实用工具、💻 编程开发等），方便分组聚合。
5. **现代极简美学**：卡片式流线布局，精心调优的动效与间距；支持明亮 / 暗黑（Dark Mode）模式一键切换。
6. **双模运行能力**：
   - **服务模式（推荐）**：通过批处理运行，数据全自动实时持久化写入 `urls.json`。
   - **离线模式**：直接双击 `index.html` 亦可离线浏览与使用，数据自动缓存至浏览器本地。
7. **数据备份保障**：支持随时一键导出 JSON 备份，或从备份文件一键恢复。

---

## 🚀 快速上手使用

1. **一键启动**：
   - 双击运行 **`启动网址管理系统.bat`**。
   - 系统将以**纯后台静默模式**启动本地服务（无黑色窗口打扰），并自动在系统默认浏览器中弹出管理界面。
   - 若系统已在运行中，再次双击也会直接为您唤起浏览器主界面。
2. **日常操作**：
   - 点击卡片直接在**新标签页**打开网站；
   - 点击右上角「**+ 添加网址**」（或使用快捷键 `Alt + N`）录入新网址，系统自动同步保存在本地 `urls.json`。
3. **安全关闭系统（提供两种方式）**：
   - **方式一（快捷脚本）**：在文件夹中双击 **`关闭网址管理系统.bat`**，系统将安全退出后台服务并在 2 秒后自动关闭。
   - **方式二（网页内直达）**：在网页界面右上角点击「⚙️」设置图标，选择「**🛑 关闭后台服务**」，无需离开浏览器即可直接关闭。

## 📂 文件目录说明

```text
网站预存/
│
├── 启动网址管理系统.bat   # Windows 一键启动脚本 (双击自启)
├── server.py             # 核心本地伴随服务 (Python 原生标准库，无 pip 依赖)
├── urls.json             # 网址与分类核心数据文件 (可随时备份、移动)
├── index.html            # 系统主界面页面
├── style.css             # 现代极简响应式样式表 (支持明暗双色主题)
├── app.js                # 前端交互与实时同步引擎
└── README.md             # 本说明文档
```

## 💡 高效使用小技巧

- **设为 Chrome 主页**：在 Chrome 设置 ->「启动时」-> 选择「打开特定网页或一组网页」-> 添加 `http://127.0.0.1:8089`。每次开启系统后打开浏览器就是你的专属工作台！
- **快捷键**：
  - `/`：快速光标聚焦到搜索框。
  - `Esc`：快速清空搜索框或关闭当前弹窗。
  - `Alt + N`：快速调出添加新网址弹窗。
