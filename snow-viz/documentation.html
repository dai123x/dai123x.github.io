🎯 一、 作品定位与四维叙事闭环

本项目面向吉林省打造“万亿级冰雪产业”战略愿景，以中共吉林省委办公厅、吉林省人民政府办公厅印发的《关于推动吉林省冰雪经济高质量发展的实施意见》（吉办发〔2024〕16号）为最高政策依据，构建了“目标解构 ➔ 空间透视 ➔ 供给支撑 ➔ 风险推演”四维叙事闭环：

01
🎯 目标解构（规划并非趋势）

解构 2027—2028 雪季（2.3 亿人次 / 4,200 亿元）与 2029—2030 雪季（3.0 亿人次 / 5,400 亿元 / 冰雪装备 50 亿元）法定目标，建立时间序列基准对照。

02
🏔️ 空间透视（3D 程序化沙盘）

自研纯 Canvas 2D 软件投影引擎，采用程序化高程噪声网格构建示意地形，映射“一主六双”空间产业走廊与重点度假区时空坐标，不做未经证实的高风险插值。

03
🎿 供给支撑（运力与硬件实绩）

对标国际 Laurent Vanat VTMH 索道运力标准，核验吉林市雪道面积（555.19 公顷，占全省近半 47.8% 居首）与全省 68 处滑雪场、14 座滑冰馆、300+ 赛事建设实绩。

04
🎲 风险推演（外生冲击与弹性）

隔离重大外生不可抗力冲击，开展蒙特卡洛 10,000 次随机游走模拟；针对极端暖冬扰动进行面板逆境弹性压力测试（气温每升 1℃ 接待量承压下降 6.8%）。

核心学术特色：诚实披露与方法论自洽
作为应用统计学专业团队，本作品最大的亮点是主动披露小样本限制（时序 n=6、截面 n=9）、如实公布留一交叉验证（LOO-R² = 0.2368）的样本外泛化衰减、坦承小聚类下的稳健推断约束，并在附录中深入审视因变量潜在循环性。我们坚持“规划目标 ≠ 历史趋势自发达成”，以量化证据论证外生政策投入对跨越式发展的决定性意义。

1. 时间序列 OLS 趋势模型与 8 项假设检验（n = 6 / df = 4）

基于 2018—2024 年全省冰雪旅游客流（单位：万人次），对 2019—2020 突发公共卫生事件年份予以事前外生隔离，有效样本确立为 n = 6（df = 4）。

数学规范说明：为何 2020 并非由“3σ 法则”剔除？
在统计学极值理论中，根据切比雪夫不等式与样本极差边界定理，样本量为 n 时，任意观测值的样本标准化偏差（Z-score）严格受限于数学上限：
|Z_max| ≤ (n - 1) / √n
当原始样本 n = 7 时，该上限为 (7 - 1) / √7 ≈ 2.268 < 3。因此，在数学上 3σ 准则在 n=7 时绝对不可能触发！本团队不套用“3σ 法则”这一不切实际的说辞，而是按照计量经济学经典范式，依据重大外生不可抗力冲击（COVID-19 突发公共卫生事件）进行事前外生隔离（Pre-estimation Exogenous Exclusion）。剔除该点后，模型残差标准误由 2,551 下降 42.9% 至 1,457 万人次。

2. 国际 VTMH 索道运力公式口径严谨说明

按瑞士滑雪专家 Laurent Vanat《全球滑雪产业年报》的国际通行标准，滑雪场每小时垂直提升力（VTMH）的标准公式为全场逐条索道“垂直提升高差 × 小时运力”求和：

VTMH = ∑i=1k [ Δh_i (m) × C_i (人/h) ] / 1000 (单位: km·人/h)

【口径与测算说明】：鉴于公开统计资料常仅披露雪场“最大落差”与“全场索道总运力”，主页面部分对标采用了最大落差代理估算量（偏上限高估值）。经我们逐条核实索道技术参数（北大湖 11 条索道，落差从 150m 至 870m 不等），北大湖实际逐条累加 VTMH 约为 13,800~14,500 km·人/h，万科松花湖约为 7,800~8,200 km·人/h。即便是按最严格口径，两大旗舰雪场依然稳居全球大型目的地领先梯队。

4. Wilson 空间相互作用引力模型公式统一

主页面与算法白皮书统一采用经典 Wilson 空间引力模型（含幂律距离衰减与广义交通阻抗成本指数项）：

T_ij = K · (P_i^α · A_j^β) / [ D_ij^γ · exp(λ · c_ij) ]

其中 P_i 为客源地人口与经济规模（基于省际高铁/民航弹性标定 α = 1.84），A_j 为吉林省黄金粉雪独占资源吸引度（β = 1.25），D_ij 为地理空间距离，c_ij 为综合旅行时空摩擦成本。

2. 针对因变量“循环性”与内生性的学术反思

学术审视：关于因变量机械构造相关性（Mechanical Endogeneity）的检视
在学术稳健性审视中，针对评价指标可能存在的机械构造内生性质疑：若因变量“冰雪指数”在定义中已经包含了“降雪资源（积雪日数）”与“设施规模（雪道面积）”的权重成分，后续再用积雪日数和雪道面积作为解释变量去回归冰雪指数，会导致模型结论中的“自然禀赋为第一驱动力”在某种程度上变成了由指标定义产生的构造性相关。

这一学术反思完全成立！在统计科学中，因变量包含自变量成分属于构造性内生（Constructed Correlation）。为证明核心结论的真实有效性，课题组特此进行了双重学术稳健性重估（Robustness Re-estimation）：
